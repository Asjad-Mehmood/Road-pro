INSTALL
  Run RoadPro_Setup.exe (download from www.exceltokml.com or GitHub
  Releases). No administrator rights needed. It installs RoadPro Hub and
  the AutoCAD plugin, and replaces any older RoadPro (v3.5 / v3.6) by itself.
  Then start AutoCAD or Civil 3D and type RDP to build a road, RDHELP for
  all commands.

  Version numbers: RoadPro 1.0.0 is the release (setup + RoadPro Hub).
  The AutoCAD plugin inside keeps its own number: v3.6.1.

WHAT IS NEW IN 1.0.0
  RoadPro Hub - a Windows app that looks after RoadPro
  - Install, update, repair or uninstall the AutoCAD plugin in one click;
    the previous version is kept and can be restored.
  - Lists the AutoCAD / Civil 3D versions on the computer.
  - Opens the user guide, shortcut keys and this file.

  Automatic updates
  - RoadPro Hub checks for a new release when it opens, and once a day
    when Windows starts (you can switch this off).
  - Update in one click: the setup is downloaded, checked (size and
    SHA-256 security code) and installed; the AutoCAD plugin is updated
    too. "Skip this version" if you do not want a particular update.
  - AutoCAD shows a notice at start-up when an update is waiting:
      ** RoadPro update 1.0.1 is available.  Type RDHUB to install it. **
  - New command RDHUB (ROADPROHUB) opens RoadPro Hub.

AUTOCAD PLUGIN v3.6  (fixes from the error report + new features)
  1. Clean tie-in at junctions (RDJ)
     - The side road now starts where the kerb returns end. Its own surface,
       edges, shoulders and barricades no longer run into the main road.
     - ONE mouth surface hatch, joined to the main road hatch : no overlap,
       no black wedges (also on skewed 60 / 120 degree junctions).
     - Shoulder bands of the main road are cut at the mouth; barricades and
       red / white edge lines adjust to the kerb returns.
     - Sidewalk / walkway / drain strips meet the corner pieces exactly,
       also with an auxiliary lane (J1-AUX) and an island.
     - Corner hatch pattern follows the through road and is drawn in pieces
       of about 25 m (no solid black fill on long corners).

  2. Roundabouts on a road (RDRB)
     - Layout : 2-way, 3-way (T) left, 3-way (T) right, 4-way (cross).
     - Side road centre line : draw new, select existing, or AUTOMATIC
       (straight, at 90 degrees, length you type - default 60 m).
     - The main road surface, shoulders, barricades and edge lines are cut
       at the ring - nothing runs into the roundabout any more.
     - Side roads start at the end of the entry / exit fillets.
     - FULL MARKING : edge lines on every approach and round every corner,
       inner ring line, entry arrows, yield lines and give-way triangles,
       lane / spiral markings as the chosen standard.

  3. Edit a curve - barricades follow (RDER, grips, live update)
     After a grip edit the bend is refitted TANGENT at its radius, so the
     barricades, edges and corridor follow cleanly (no crossing units).

  4. Move a centre line - everything follows
     Junction and roundabout side roads keep their start on the moved road
     (RDB and live update), with the same clean mouth.

  5. Cross section (RDX) - professional
     - Drawn only up to the CORRIDOR LIMIT (outer edge of the utility /
       drain / walkway), with a corridor limit line on each side.
     - Dimension row 1 : every component with its name (LANE, SHOULDER,
       BARRIER, SIDEWALK, WALKWAY, DRAIN, UTILITY, VERGE).
       Row 2 : left roadside / carriageway / right roadside.
       Row 3 : corridor width (limit to limit).
       Architectural ticks on all dimensions.
     - OFFSET / FINISHED LEVEL table under the section (levels relative to
       the centre line finished level).
     - Corridor item notes on staggered rows with leaders (no overlap with
       the barrier and sign notes).

  Everything else is unchanged from v3.5.
