Free · Works with AutoCAD 2013 or newer, Civil 3D and Map 3D (not AutoCAD LT) · Windows 10 / 11 · No administrator rights needed.

If Windows shows “Windows protected your PC”, click More info → Run anyway.

Install once — updates arrive by themselves

  • Run RoadPro_Setup.exe: it installs RoadPro Hub and the AutoCAD plugin.
  • Start AutoCAD and type RDP to build a road, RDHELP for all commands.
  • New versions are offered automatically; AutoCAD shows a notice and RDHUB updates in one click.
  • Every update is checked (SHA-256) before it is installed.
